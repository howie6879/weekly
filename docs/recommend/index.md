- 📦 便携打包 - 生成可执行文件（支持 Windows/macOS/Linux）
- 🔒 隐私保护 - 本地存储配置数据，无需云端同步
- 🌍 多平台支持 - 完美运行于主流操作系统
- 🎮无需复杂配置即可自由添加站点
